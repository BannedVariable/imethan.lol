# imethan.lol

A sleek, dark-themed portfolio site built with **React + TypeScript + Vite**.

## ✨ Features

- **Custom Music Player** — Built-in player with 2 songs, progress tracking, and volume control
- **Live Discord RPC** — Shows your Discord status via Lanyard API
- **Smooth Animations** — Glitch effects, fade-ins, and gradient hover states
- **Dark Theme** — Black & white color scheme with accent gradients
- **Responsive Design** — Works on desktop and mobile
- **Fast & Lightweight** — Vite-powered for instant load times

## 🚀 Getting Started

### Prerequisites
- Node.js 16+
- pnpm

### Installation

```bash
git clone https://github.com/yourusername/imethan.lol.git
cd imethan.lol/artifacts/imtheo-rebuild
pnpm install
```

### Development

```bash
pnpm run dev
```

Visit `http://localhost:5173`

### Build

```bash
pnpm run build
```

## 🎵 Music Player

- Supports multiple songs
- Real-time progress bar with white fill
- Volume control with dynamic icon
- Auto-plays on page load
- Next/Previous/Play-Pause controls

## 🔧 Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
